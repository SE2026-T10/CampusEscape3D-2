# Architecture Decisions

Thư mục này lưu ADR cho quyết định kiến trúc có ảnh hưởng đáng kể tới nhiều module, API dùng chung, lifecycle hoặc cấu trúc map. Không cần ADR cho sửa lỗi/đổi nội dung cục bộ.

Tạo file `NNNN-short-title.md` khi có quyết định mới, với các mục:

1. **Bối cảnh**
2. **Vấn đề**
3. **Quyết định**
4. **Lý do lựa chọn**
5. **Phương án đã cân nhắc**
6. **Ảnh hưởng tới module/map khác**
7. **Trạng thái** (đề xuất/được chấp thuận/thay thế)

Hiện chưa có ADR được ghi nhận trong bộ tài liệu AI.
