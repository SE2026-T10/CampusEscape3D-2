# Campus Escape 3D v1.1.0 — Expanded Library

A second, larger map next to the original level. Choose either one from the main menu.

## What's new

- **Map selection:** the main menu lists **Library Tutorial** (the v1.0.0 level, unchanged) and **Expanded Library**. Restart reloads the map you are on; Main menu takes you back to the choice.
- **Expanded Library:**
  - two floors and six zones: Entrance & Lobby, Main Book Stacks, Reading Rooms & Study Wing, the Restricted Service Corridor, Staff Offices & Upper Stacks, and the Restricted Archive;
  - three stairs, so a guarded stair always has a quieter alternative;
  - six guards with the same AI as the tutorial (patrol, investigate, chase); they notice and chase faster here;
  - a five-objective mission: get in, take a staff access card from Office 2 upstairs, steal the rare manuscript from the archive vault, unlock the archive's back gate from inside and escape through the loading dock;
  - card doors and one-way doors that guards can't see through while closed;
  - three checkpoints (Study Rooms, Staff Offices, Storage); being caught undoes everything since the last one, doors included;
  - hiding spots marked on the floor; red signs on restricted doors;
  - dressed in the tutorial's low-poly library look.

## Download

`CampusEscape3D-1.1.0-windows-x64.zip`:
- unzip it and run `CampusEscape3D.exe`;
- keep `CampusEscape3D.pck` next to it.

Built by GitHub Actions with Godot 4.7.2 stable; see `docs/BUILD.md`.

## Controls

The same as v1.0.0:

| Key | Action |
|---|---|
| W A S D | move |
| Shift | sprint |
| C / Ctrl | crouch |
| E | use (cards, doors, the manuscript, exits) |
| Mouse | look |
| Esc / P | pause |

## Known limitations

- **Not signed:** Windows SmartScreen may warn the first time you run it.
- **Testing:** the automated suite, the game-flow and map-selection runs and the export pass on Linux. For this version, the exported game has not yet been launched on Windows, the Expanded Library has not been played to the end by a person, and its frame rate has not been measured on Windows. Its planned 20–30 minute first completion is unconfirmed.
- **Performance:** on the development VM (no GPU) the Expanded Library runs at about 93% of the tutorial's frame rate. Windows results: `docs/performance/release_1_1/`.

The full list is in the README (Known limitations) and in `docs/expanded/phase-7-release.md`.
