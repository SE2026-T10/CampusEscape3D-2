# Campus Escape 3D v1.2.0 — Expanded Library expansion

A much bigger Expanded Library: a basement, new systems and three ways out. The Library Tutorial is unchanged.

## What's new

- **Bigger map:** a basement service network is added under the two floors, making seven zones. There are seven guards; one patrols the basement.
- **Free exploration with clear prerequisites:**
  - get in;
  - find a staff access card and the tool kit;
  - open the electrical panel and restore the vault's power;
  - crack the vault keypad using clues;
  - take the rare manuscript.
- **Three escape routes,** each with its own requirements. The win screen names the route you used.
  - **Main entrance:** it locks behind you. The security master badge and an override at the lobby reader open it.
  - **Loading dock:** its shutter needs SERVICE EXIT power, and the release has to be freed with the tool kit and set to OPEN.
  - **Maintenance passage:** a hidden passage in the basement that leads to the storm drain.
- **Optional puzzles:** the pump, a security locker and the archive's back-gate shortcut.
- **Security:**
  - Four cameras on a SURVEILLANCE circuit raise the alarm when they spot you. Guards come to look, but the alarm never ends the run.
  - Switches in the electrical room can turn the cameras off, or give the loading-dock shutter SERVICE EXIT power. Switching to SERVICE EXIT reboots the cameras.
  - Guards check hiding spots near where they search. A hiding spot only hides you if nobody saw you get in.
- **Stamina and inventory:**
  - Sprinting uses stamina: 5 s from full, refilling 1 s after you stop.
  - You can carry up to three items (tool kit, staff card, distractions). Press 1–3 to select one and F to throw a distraction.
- **Journal:** press J to read the clue documents you have collected. Clues on the walls are mounted on notice boards with a small light, and show a floating "!" until you read them.
- **HUD:**
  - A WAYS OUT list shows only the escape routes and requirements you have discovered.
  - It also shows the power circuits once you have seen the switch board, and your last checkpoint.
- **Settings** (main menu and pause menu, both maps):
  - interface size 90 / 100 / 110 / 125 %;
  - master volume;
  - sound captions with a direction arrow (on by default).
- **New look:** redesigned lobby, main entrance and porch, study rooms, service corridor, service stair landings and archive gates. The library's founding year now appears on a large cornerstone on the lobby's north wall.

## Download

`CampusEscape3D-1.2.0-windows-x64.zip`:
- unzip it and run `CampusEscape3D.exe`;
- keep `CampusEscape3D.pck` next to it.

Built by GitHub Actions with Godot 4.7.2 stable; see `docs/BUILD.md`.

## Controls

| Key | Action |
|---|---|
| W A S D | move |
| Shift | sprint (uses stamina in the Expanded Library) |
| C / Ctrl | crouch |
| E | use |
| 1 / 2 / 3 | select a carried item (Expanded Library) |
| F | use the selected item: throw a distraction (Expanded Library) |
| J | journal (Expanded Library) |
| Mouse | look |
| Esc / P | pause |

## Known limitations

- **Not signed:** Windows SmartScreen may warn you the first time you run it.
- **Testing:** the automated suite and the export pass on Linux. For this version:
  - the exported game has not been played to the end on Windows;
  - the Expanded Library's frame rate has not been measured on Windows;
  - no human playtest has confirmed how long a first completion takes.
- **Performance:** the Expanded Library scene is much larger than in 1.1.0. Check its frame rate on your hardware.

The full list is in the README (Known limitations).
