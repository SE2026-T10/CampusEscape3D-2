# Campus Escape 3D v1.0.0 — MVP

The first complete release: one playable low-poly university library, from the main menu to escape.

## What's in it

- **First-person stealth:** walk, sprint and crouch; hide in study carrels.
- **Three guards:**
  - they patrol, investigate what they see or hear, and chase;
  - each has a 90° / 14 m vision cone, a detection meter and hearing.
- **Objectives:** take the access card from the Restricted Stacks and escape through the exit door. Two routes in, two routes out.
- **Checkpoints and respawn:**
  - two checkpoints;
  - being caught sends you back to the last one, with the guards reset.
- **Menus:** main menu, pause menu (Esc / P), caught screen, win screen with time and catches.
- **Sound:** generated sound effects, ambience and music.
- **Guards' look:** an animated low-poly guard model.

## Download

`CampusEscape3D-1.0.0-windows-x64.zip`:
- unzip it and run `CampusEscape3D.exe`;
- keep `CampusEscape3D.pck` next to it.

Built by GitHub Actions with Godot 4.7.2 stable; see `docs/BUILD.md`.

## Controls

| Key | Action |
|---|---|
| W A S D | move |
| Shift | sprint |
| C / Ctrl | crouch |
| E | use |
| Mouse | look |
| Esc / P | pause |

## Known limitations

- **Not signed:** the executable has no code signature, so Windows SmartScreen may warn the first time you run it.
- **Test coverage:** the automated suite and game-flow run pass on Linux (CI) and on Windows 10. The release-candidate build (CI, commit `15b3ebf`) was launched on Windows and played into the level on an NVIDIA GeForce MX130. A full manual pass (audio by ear, feel, difficulty) is still listed in `docs/qa/REGRESSION_CHECKLIST.md`.
