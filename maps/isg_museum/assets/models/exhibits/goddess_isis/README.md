# Goddess Isis, 1st century CE

Chưa có tệp model trong thư mục này. Endpoint tải chính thức của Sketchfab trả HTTP 401 vì cần xác thực.

Mở [trang asset](https://sketchfab.com/3d-models/goddess-isis-1st-century-ce-fef83e3711e248689702f953e02809a0), đăng nhập rồi chọn **Download 3D Model**. Ưu tiên GLB hoặc glTF. Giữ đủ tệp `.gltf`, `.bin` và texture nếu tải glTF; để gói ZIP gốc trong `.local/downloads/museum_models/sketchfab`.

Sau khi có tệp cần kiểm tra model bằng Godot rồi mới đổi trạng thái trong `source.json` và danh mục chung. Không thêm model vào scene chơi trong bước chuẩn bị này.

- The original is bronze; a light stone material and a separate solid pedestal are proposed for the courtyard.
- Preserve the original model; make a separate adapted scene when integrating.
